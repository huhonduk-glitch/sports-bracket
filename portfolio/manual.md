## 처음 시작하기

1. 앱 주소를 열거나, 내려받은 HTML 파일을 더블클릭하면 브라우저에서 바로 열려요. 설치는 필요 없어요.
2. 맨 위 **＋ 새 대회**로 대회를 만들어요. 화면 위쪽에 1~5단계 안내가 있어요.
3. 처음이라면 **처음이신가요?** 안내를 열어 보세요.

![첫 화면과 단계 안내](images/manual-01.png)

| 순서 | 할 일 | 걸리는 시간 |
| --- | --- | --- |
| 1 | 👥 팀 편성 → 학생 명단 넣기 | 1분 |
| 2 | 팀당 인원 · 성별 · 수준 설정 → 팀 자동 편성 | 30초 |
| 3 | 대진표로 보내기 → 대회 설정 | 5초 |
| 4 | 대회 방식 · 점수 방식 · 일정 정하기 → 대진표 만들기 | 1분 |
| 5 | 스코어보드에서 점수 넣기 → 결과 확정 | 경기 중 |
| 6 | 팀 현황에서 순위 · 개인 기록 보기 | 수시 |

## 1단계 · 팀 편성

### 학생 명단 넣기 (3가지 방법)

| 방법 | 설명 |
| --- | --- |
| ✏️ 직접 입력 | 번호 · 이름 · 성별 · 수준을 넣고 추가. Enter로 빠르게 넣어요 |
| 📝 일괄 입력 | 한 줄에 한 명씩 `번호 이름 성별 수준` (예: `1 학생A 여 상`, 성별 · 수준은 빼도 돼요) |
| 📁 파일 업로드 | CSV · TXT 파일을 끌어다 놓거나 눌러서 골라요. 나이스 명렬표도 돼요 |

명단 아래 **모두 남 · 모두 여 · 모두 상/중/하** 버튼으로 한 번에 바꿀 수 있어요.

![학생 명단 넣기](images/manual-02.png)

### 팀 나누기 설정

- **팀당 인원**, **성별 균등**, **수준 균형**을 정해요. 수준 균형을 켜면 팀 전력이 비슷해지게 나눠요.
- **짝 조건**: '같은 팀 금지'나 '반드시 같은 팀'을 걸 수 있어요.
- **학급 명단 보관함**에 자주 쓰는 반 명단을 저장해 두면 다음에 불러오기 한 번으로 끝나요.
- **팀 자동 편성**을 누르면 팀이 나뉘어요.

![팀 자동 편성 결과](images/manual-03.png)

## 2단계 · 대회 설정

### 대회 방식

| 방식 | 설명 | 이럴 때 |
| --- | --- | --- |
| 🏆 토너먼트 | 지면 탈락. 3위 결정전 · 부전승 팀 지정 가능 | 체육대회, 짧은 대회 |
| 📊 리그전 | 모든 팀이 서로 한 번씩. 승점으로 순위 | 수업 중 긴 리그 |
| 🏅 조별 + 토너먼트 | 조별 리그 뒤 위 팀이 본선 진출 | 월드컵 방식 |

### 점수 방식 · 득점자 기록

- **단일 점수**(축구 · 피구 · 농구), **3세트제**(배드민턴 · 탁구), **5세트제**(배구) 중에서 골라요.
- **득점자 기록**을 켜면 점수를 올릴 때 선수를 고르는 창이 떠서, 팀 현황에 개인 기록이 쌓여요.

### 일정

- **날마다 연속**(체육대회) / **체육 수업 요일만**(정규 수업 리그) / **날짜 직접 지정** 중에서 골라요.
- 코트 수(1~6), 경기 시간, 쉬는 시간, 하루 최대 경기 수를 정할 수 있어요.

대회 이름을 넣고 **대진표 만들기**를 눌러요.

![대회 설정 화면](images/manual-04.png)

## 3단계 · 대진표

- 경기 카드를 누르면 점수 입력 창이 떠요. 결과를 저장하면 이긴 팀이 다음 경기로 올라가요.
- **인쇄**(PDF 저장 가능) · **이미지로 저장** · **QR코드**로 학생들에게 나눠 줘요.
- **다시 추첨**은 팀 순서를 새로 섞고, **결과 초기화**는 모든 경기 결과를 지워요.

![토너먼트 대진표](images/manual-05.png)

## 4단계 · 경기 일정

- **목록으로 보기**와 **날짜별로 보기**(달력) 중에서 골라 봐요.
- 비가 오거나 행사가 생기면 **일정 미루기**로 뒤 경기를 한꺼번에 미뤄요.

![경기 일정 달력](images/manual-06.png)

## 5단계 · 점수 입력 · 타이머

1. 코트 수(1~6)를 고르고 코트마다 경기를 골라요.
2. **＋ / −** 버튼으로 점수를 넣어요. 세트제면 지금 세트가 강조돼요.
3. 타이머 시간을 고르고 **▶ 시작**을 눌러요.
4. 경기가 끝나면 **✅ 결과 확정** → 대진표에 바로 반영돼요.
5. **전광판 모드로 보기**로 TV나 빔에 크게 띄울 수 있어요.

![멀티 스코어보드](images/manual-07.png)

## 팀 현황

스코어보드에 기록한 내용으로 팀 순위, 개인 득점, 경고 · 퇴장을 자동으로 모아 보여 줘요.

![팀 현황 화면](images/manual-08.png)

## 백업 · 되돌리기

- 자료는 이 브라우저에 저장돼요. 맨 위 **백업 저장**으로 파일을 받아 두고, **백업 열기**로 되살려요.
- 실수했을 때는 **되돌리기**를 눌러요.

## 자주 묻는 질문

| 질문 | 답 |
| --- | --- |
| 인터넷이 없어도 되나요? | 네. 이미지 저장 · QR 말고는 인터넷 없이 동작해요. |
| 팀 수가 딱 떨어지지 않으면요? | 토너먼트에서 부전승(첫 경기 없이 다음 라운드)이 생기고, 부전승 팀을 직접 고를 수 있어요. |
