👥 팀 편성

학생 명단 등록 (3가지 방법)

방법설명
✏️ 직접 입력번호, 이름, 성별, 수준 입력 후 추가. Enter키로 빠르게 추가 가능
📝 일괄 입력한 줄에 한 명씩 입력. 형식: 번호 이름 성별 수준 (성별·수준 생략 가능)
📁 파일 업로드CSV, TXT 파일 드래그 or 클릭. NEIS 명렬표도 OK!

수준(실력) 설정

학생별로 상(A) / 중(B) / 하(C) 수준을 지정할 수 있습니다.
팀 편성 시 "수준 균형: 균등 배분"을 선택하면 상+하를 한 팀, 중+중을 한 팀으로 편성해 팀 전력을 균등하게 맞춥니다.

⚙️ 대회 설정

대회 방식

방식설명추천 상황
🏆 토너먼트패배하면 탈락. 3위 결정전·시드·부전승 팀 지정 가능체육대회, 단기전
📊 리그전모든 팀이 서로 대전. 승점으로 순위 결정. 1~4라운드수업 중 장기 리그
🏅 조별+토너먼트조별 리그 후 상위팀이 본선 진출월드컵 방식

스코어 방식

방식설명추천 종목
🔢 단일 점수총점으로 승패 결정축구, 피구, 농구
🏸 3세트제2세트 선승. 세트별 점수 입력배드민턴, 탁구
🏓 5세트제3세트 선승. 세트별 점수 입력배구, 탁구(국제)

득점자 기록 (NEW)

설정동작추천 종목
✅ ON득점 시 선수 선택 팝업 → 팀현황에 개인 기록 자동 집계축구, 농구, 핸드볼 등 단체 종목
⬜ OFF팝업 없이 점수만 바로 올라감배드민턴, 탁구, 단식 등

부전승 설정 (토너먼트)

참가 팀 수가 2의 거듭제곱이 아닐 때 부전승이 필요하며, 부전승 팀을 직접 선택할 수 있습니다.

일정 설정 (3가지 모드)

모드설명추천 상황
📅 연속일시작일부터 매일 연속 배정체육대회
🗓️ 요일 선택체육 수업 요일만 선택하면 해당 요일에만 배정정규 수업 리그전
✏️ 직접 지정날짜를 하나씩 추가. 같은 날 여러 경기 가능불규칙 일정

코트 수(1~6)·경기 시간·쉬는 시간·하루 최대 경기 수 설정 가능

🏅 대진표 탭

생성된 대진표에서 경기 카드를 클릭하면 점수 입력 모달이 뜹니다.
세트제의 경우 세트별 점수를 각각 입력합니다.
결과 저장 시 다음 라운드에 승자가 자동 배치됩니다.
토너먼트: 라운드별(16강·8강·4강·결승) 일정이 별도 표시됩니다.

버튼기능
🔀 재추첨팀 순서를 다시 섞고 대진표 새로 생성
↩️ 초기화모든 경기 결과를 지우고 처음부터
🖨️ 인쇄브라우저 인쇄 (PDF 저장 가능)
📸 이미지 저장대진표를 PNG 이미지로 다운로드
📱 QR코드대진표 정보 QR 생성 (온라인 배포 시)

📅 일정 탭

리스트 뷰와 달력 뷰 제공 / 경기 수·완료 경기·진행 기간 요약 표시
토너먼트 라운드별 일정이 구분되어 표시됩니다.

📊 멀티 스코어보드

최대 6코트 동시 운영! 각 코트별 독립 점수판 + 타이머.

사용법:
1. 코트 수 선택 (1~6)
2. 각 코트에서 경기 선택
3. +/− 버튼으로 점수 입력
4. 세트 스코어: 현재 세트 강조 표시, 세트 승패 아이콘(🟢/🔴)
5. 타이머 시간 선택 → ▶ 시작
6. 득점자 기록 ON 시: 득점 선수·경고·퇴장 기록 가능
7. 경기 끝나면 "✅ 결과 확정" → 대진표에 자동 반영
